A

The Canon

5 islands

The skills that build, tune, and govern the skills themselves — the layer that keeps the archipelago honest about its own construction.

idc-skill-authoring

model

The skill layer of the canon — folder anatomy, progressive disclosure, invocation and router skills, the Codex sidecar, fleet distribution, and the evidence discipline.

writing-for-agents

model

The universal levers for any document an agent reads — context pointers, the two loads, information hierarchy, completion criteria, leading words, pruning, failure modes.

skill-tune

modelICM

Empirically improve a skill or context file — run, judge, edit, re-run — and keep an edit only when a measured score rises. A tuned file is usually a shorter file.

skill-supply-chain-review

model

Audit a third-party skill before adopting it — provenance, hidden invocation, dangerous instructions, injection surface — and emit a trust verdict bound to a pinned version.

skill-duel

userIDC-native

Run an incumbent against a challenger through one identical gauntlet and return a swap / no-swap verdict welded to the scores. The mechanical governor of the capped pack.

B

Evidence & Review

7 islands

The one law made mechanical — checks that can actually fail, verdicts that void on move, and receipts a reviewer recomputes instead of trusting.

cross-family-review

modelcrown

The crown ceremony: an independent reviewer from a different model family reviews a diff at an exact head along Standards and Spec axes; the verdict voids on move. The author never reviews their own work.

finding-register

modelIDC-native

A durable register of findings each enumerated at an exact SHA — not a running count — provenance-marked both ways, with a collision-free id swept before allocation.

evidence-packet

modelIDC-native

Assemble a byte-verifiable packet — diff, verification-ladder commands, captured outputs — so a reviewer recomputes every claim. A weak and a frontier author are equally mergeable when both can run the ladder.

connected-fix-prompt

user

Compose one dependency-ordered refinement prompt from a set of findings — ranked root-cause-before-symptom, each carrying recomputable evidence — so a fixer clears them in a single correct-order pass.

computer-use-smoke

model

Drive a real UI through a scripted smoke path and assert observable outcomes — the runtime primitive that produces the band-4 evidence archipelago demands. A verdict is an assertion; a screenshot is triage.

self-contained-ship

model

Prove a deliverable phones home to nobody — a static egress scanner paired with a sealed offline load asserting zero outbound. The containment gate; transport proves liveness, not containment.

exposure-audit

model

Read-only exposure audit of a machine or repo against a named advisory — enumerate what is installed and reachable, decide affected-or-not on captured evidence, write a structured report. Never remediate.

C

Build Protocols

7 islands

Evidence-gated construction, from a throwaway spike to a tamper-evident full-cycle build — with gates that must be able to fail and band caps you cannot talk past.

archipelago

model

The full-cycle, evidence-gated build protocol — typed contracts at every seam, gates that must be able to fail, loopback routing, a tamper-evident ledger, and band caps you cannot talk your way past.

gauntlet-loop

user

Convert any task into a fan-out of builder sub-agents each shadowed by a blind critic, looped against a falsifiable bar. The lightweight cousin of archipelago; graduate up when the bar must be a real gate.

spec-pipeline

model

One pipeline from a discussed feature to shipped code: spec synthesis, then tracer-bullet tickets with blocking edges, implement at pre-agreed seams with TDD, then an optional persistent goal loop.

prototype

model

Build a throwaway prototype to answer one design question — a shareable HTML file for a state question, or switchable UI variants for a look question — then capture the answer and discard the code.

diagnose

model

A disciplined loop for hard bugs: build a tight red-capable feedback loop first, reproduce and minimise, hypothesise, instrument, fix with a regression test. Performance is judged by operation counts, not wall-clock.

merge-resolve

model

Resolve an in-progress merge or rebase by tracing every conflicting hunk to the intent that authored it, keeping both where they compose, recording the trade-off where they collide, never aborting, checks before finishing.

transport-complete

model

Ship a change and babysit it until verifiably live — commit, push, watch CI, confirm the deploy promoted the exact SHA, prove production serves it. Done means a health check for that SHA, not a successful push.

D

Planning & Delegation

8 islands

Thinking before building — should this exist at all, who decides, and how a task travels between agents and humans without dropping its state.

job-to-be-done

modelICM

The pre-build triage: should a thing be built or automated at all, and where does the human stay in the loop — delegation / complexity / outcome, the 90/10 rule. Its best outcome is often “don't build it”.

grill

model

Relentless interview to reach shared understanding before building, in three modes — ambush, drill, batch — emitting settled decisions as ADRs. Facts are looked up; only decisions are asked.

wayfinder

user

Plan a chunk of work too big for one session — chart it as a shared map of decision tickets, then resolve them one at a time until the way to the destination is clear. Plans by resolving decisions, not slicing a build.

to-questionnaire

user

Turn a decision you can't answer alone into a Markdown questionnaire for the one person who can — filled async or together. Grills you about the send, not the subject. The inverse of grill.

issue-triage

model

Move a queue of issues you did not create through a triage state machine, grill for missing info, and emit durable agent-ready briefs — every AI note carrying an honesty disclaimer. The inbound on-ramp.

delegated-authority-prompt

userICM

Compose a minimum-question, maximum-authority delegation prompt in five slots so an agent runs far without check-ins, made safe by the tripwires that bound it. The mirror of grill — this front-loads the answers.

handoff

user

Compact a session into a state-based handoff a fresh agent resumes from with zero memory, plus the wake protocol the receiver runs — re-reading verdicts and register state from the tree before trusting the summary.

model-routing

model

Route one task to the cheapest model or tool that still clears its cognitive-demand floor — vision-native, deep-reasoning, cheap-bulk — and record why the pick clears the bar. The only island that selects the model a step runs on.

E

Workspaces & Architecture

8 islands

Folders and markdown as agent architecture — scaffold a workspace, keep the map honest against the tree, model the domain, and find the seams worth deepening.

folder-workspace

modelICM

Structure a repo as an ICM workspace — folders and markdown as architecture, routed by a three-layer map so one agent becomes the agent each task needs, without agent swarms. The map is an auditable routing contract.

workspace-scaffold

modelICM

Scaffold a new ICM workspace for a domain — generate the root map, the rooms, the naming conventions — then prove a fresh agent routes through it before declaring done. Ships scaffold.sh.

workspace-audit

modelICM

Audit an ICM workspace for drift — every path the map claims exists in the tree, and no live room missing from the map. The map is a claim; the tree is the evidence; drift is a claim the evidence contradicts.

data-source-map

modelICM

Wire an external data source into a workspace with a markdown descriptor — where the store lives, what it holds, what to ask it — so an agent queries it on demand instead of ingesting it. A map to live data, not a copy.

productionize-opinion

modelICM

Distill an operator's own raw material — transcripts, notes, decisions — into durable workspace context that carries their voice and process. Mines you, not external sources; inferences are marked as inferences.

domain-modeling

model

Actively build and sharpen a project's domain model — challenge terms, invent edge-case scenarios, write the glossary and decisions the moment they crystallise. The active discipline, distinct from reading CONTEXT.md.

deep-modules

model

Shared vocabulary and enforcement for deep modules — a lot of behaviour behind a small interface at a clean seam — with the dependency-cruiser rules that make entry points the only way in.

arch-survey

model

Proactively survey a whole codebase for refactor opportunities — mine change-history hot-spots, gate each through the deep-module deletion test, rank them as a before/after report. The scan that runs before deep-modules designs one.

F

Fleet & Infrastructure

6 islands

The ground the fleet runs on — coordination across machines, the mechanical guardrails under the prompts, versioned consoles, wired domains, and the one time-triggered island.

worktree-fleet

user

Git worktrees for same-machine parallel agents, with the IDC boundary — adopted for drafts, forbidden for evidence. Worktree artifacts are inadmissible as gate evidence until re-derived from a fresh clone.

lane-claim

modelIDC-native

Declare-and-halt coordination for agents working one repo across many machines — claim a lane before touching it, halt if already claimed, release when done. Cures the cross-machine collisions worktrees cannot.

agent-guardrails

model

Four mechanical layers under an AI fleet — shell denylist, git block, pre-commit gate, read-only data role — mechanizing the covenants beneath the prompts.

console-as-code

modelIDC-native

Assemble an agent's operating prompt from versioned in-repo blocks, stamped with the assembly SHA — so every prompt is an auditable artifact and the same console assembles identically on every seat.

domain-wire

modelIDC-native

Wire a domain the IDC way — the three-lane model, one canonical per venture with siblings 308-redirecting to it, automatic graduation when a brand deed exists, and canonicals moving in the same commit.

agent-schedule

model

Schedule an unattended agent on a recurring wall-clock — cron, systemd, heartbeat — then verify the schedule actually fired before trusting it. The only island triggered by time; every loop sibling is condition-driven.

G

Research, Prose & Communication

9 islands

Everything that turns sources into grounded output and output into something a human actually understands — cited research, video, prose, teaching, and the small sharp compressors.

research

model

Investigate a question against high-trust primary sources and capture findings as a cited Markdown file — every claim sourced or explicitly flagged unverified. DeepAPI is an optional backend.

video-analysis

model

Turn a video URL into a grounded analysis from two channels — the transcript (what was said) and deduped frames (what was shown) — every claim cited to a transcript line or a frame number. Ships grab.sh.

prose-craft

user

Author original prose in two phases — EXPLORE mines fragments and coins the load-bearing leading word; EXPLOIT builds grounded beats where no beat leans on an ungrounded concept, optionally shaping each block's form.

ai-humanizer

model

Detect and score AI-writing tells in prose — a bundled statistical + pattern scorer emitting a deterministic 0–100 AI-likeness number — so a de-slop pass yields byte-verifiable before/after evidence, not a claim.

teach

user

A stateful multi-session teaching workspace — mission-grounded lessons from high-trust sources, delivered as beautiful self-contained HTML with tight feedback loops and learning records.

wizard

model

Generate an interactive bash wizard that walks a human through steps only they can perform — opening each URL, saying what to click, capturing values into .env files and CI secrets. Ships a fixed template.sh UX library.

batch-sample-curate

user

Draw N candidates from a probabilistic-output tool and curate to the best against a scored keep/cut ledger, recording why each was kept or cut. Distinct from gauntlet-loop (refine one to a bar) and prototype.

wait-what

user

Stop — that last message did not land. Re-pitch it with the missing context, in ASD-STE100 Simplified Technical English, grounded in the project's own CONTEXT.md ubiquitous language.

short

user

Compress the current answer — strip filler, simplify wording, cut length while keeping substance.

04

The moat

Most of the fifty are the best public technique, vendor-stripped and welded to the evidence law. That is valuable, but it is not defensible — anyone can re-fuse the same canons.

Six islands exist nowhere else. They are not adaptations; they were invented for the way IDC actually runs — one repo, many machines, evidence over claims. Add the ICM cluster welded to the evidence law, and the cross-family review ceremony backed by production receipts, and the pack stops being a re-fusion anyone could copy.

The defensible core is not the techniques. It is the six that only IDC needed to build.

That is the moat: not breadth, but the handful of islands whose reason to exist is IDC's own operating reality — coordination across machines, a durable register at an exact SHA, the three-lane domain doctrine, the versioned console, the recomputable evidence packet, and the governor that keeps the fifty honest.

lane-claim
Cross-machine declare-and-halt — the collision worktrees cannot cure.
finding-register
Findings enumerated at an exact SHA, provenance both ways, collision-free ids.
domain-wire
The three-lane doctrine — one canonical, siblings 308, automatic graduation.
console-as-code
Operating prompts assembled from versioned blocks, stamped with the assembly SHA.
evidence-packet
A byte-verifiable bundle a reviewer recomputes instead of trusting.
skill-duel
The displacement governor — the fifty change only by a won duel.
05

Governance — the living deadlock

Fifty is a cap, and a cap only means something if it is mechanically enforced. The pack governs itself the same way it vets itself: nothing crosses on a claim.

The governor

skill-duel

A challenger cannot argue its way in. It enters exactly one identical gauntlet against a named incumbent — the same executor cases, the same defect-tied critic, the same seat — and the verdict is welded to the scores it earned.

  • Same cases, same critic, same seat — no re-framing the contest.
  • The verdict is swap or no-swap, bound to the numbers.
  • The author never judges their own challenger.
The swap rule

How the fifty change

The pack is a living deadlock. There are only two doors in, and both require beating the bar rather than pleading for it.

  • A challenger displaces an incumbent only by strictly winning the head-to-head gauntlet. A tie keeps the seat.
  • Or it fills a deprecated slot — but only by clearing ≥9 on its own gauntlet.
  • The duel pool waits outside: meeting-transcript, safe-rewrite, purchase-research, leonardo-tournament — challengers, not slots.

needs work

8.5/10 · coherence passes

07

How every island was judged

One vetting method, run honestly, with two lenses that must never be conflated. Every island demonstrates its own discipline; the vetting demonstrates the one law.

Executor runs 3 live challenge cases → in a sandbox → Blind adversarial critic scores → defect-tied rubric
Lens one · the promotion gate

Defect-tied confidence

Confidence is not a vibe. It is ten minus the count of real, unaddressed, in-scope defects a blind critic can actually stand up. A number you can argue with, because it points at named holes.

confidence = 10 − Σ (real unaddressed in-scope defects)

Under this lens all islands cleared ≥9 with zero unaddressed defects standing. Adversarial re-vetting is an asymptote — fresh executors invent new marginal edges every round — so the honest close is “all real defects fixed and verified”, not “looped until everyone says 10”.

Lens two · the documentation pass

Generic case performance

A separate fan-out ran three fresh in-scope challenge cases per skill on the final code and scored generically — case performance averaged around 8.7 (range 8.0–9.3).

The lower generic “confidence” that pass reported is documenter caution, not new defects. Conflating the two lenses is the mistake; one counts standing holes, the other rates a run. It surfaced exactly one real honesty fix, already applied — a fleet-topology claim softened so seats can be independent dirs, not only symlinks.

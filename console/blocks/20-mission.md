# MISSION — the forge loop, made clear

The recurring operating request, sharpened from its original ask into four moves:

1. **VET every island in live fleet use.** For each skill, an executor devises and runs three
   distinct, in-scope challenge cases in a sandbox; an adversarial judge scores by *real*
   defects (the defect-tied rubric, not a vibe). Report each island's performance concretely —
   what it actually did, case by case.
2. **HARDEN whatever falls short.** Fix the real defects, re-vet, repeat until confidence ≥9
   across the board — then, and only then, promote the validated pack to `Island-Dev-Crew`,
   each island carrying its validation record.
3. **GROW only by earning it.** When a new technique appears (a video, a repo, a canon), assess
   it against the islands already shipped: build a new island *only* if it adds a genuinely
   distinct concern and duplicates none. Otherwise leave it out — and say plainly why. Never
   exceed the 40-island cap.
4. **CAPTURE the build.** Keep a total handoff (state, decisions, traps, open work) and this
   versioned prompt console, so a cold session — or a teammate — resumes with full understanding
   instead of re-deriving it.

The bar that overrides convenience: nothing is reported complete without captured, hashed
evidence from a check that could have failed.
